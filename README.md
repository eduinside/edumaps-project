# 📍 EduMaps (에듀맵스)

**EduMaps**는 대구광역시교육청의 *2025 초등 자기주도학습 정보모아* 사업 취지를 웹으로 구현한 플랫폼입니다. 구글 스프레드시트를 데이터베이스로 활용하여 현장체험학습 장소와 온라인 학습 자원을 지도로 시각화하고, 학년별 맞춤 로드맵을 제공합니다.

## 🌟 핵심 가치
- **관리의 편리함**: 개발 지식이 없어도 구글 시트 수정만으로 사이트 전체를 업데이트할 수 있습니다.
- **최고의 성능**: Next.js ISR 기술로 0ms에 가까운 로딩 속도를 보장합니다.
- **연동의 깊이**: 체험학습 장소에서 관련 로드맵으로 즉시 이동하는 깊은 인터랙션을 제공합니다.

## 📖 학년별 로드맵 기능 소개

### 특징
- **교과 단원 연계**: 각 체험학습 장소·온라인 자원이 어떤 학년의 어떤 단원과 연결되는지 한눈에 파악할 수 있습니다.
- **학년별 맞춤 필터링**: 1~6학년 버튼을 눌러 해당 학년에 적합한 자원만 골라볼 수 있습니다. 학년을 선택하지 않으면 전체 로드맵 자원이 표시됩니다.
- **교육과정 순서 정렬**: 학년을 선택하면 활용 시트에 등록된 순서(교육과정 흐름)대로 자원이 정렬되어, 수업 계획 시 참고하기 좋습니다.
- **체험학습 연계**: 체험학습 탭에서 장소를 선택한 뒤 "관련 로드맵 보기" 버튼을 누르면, 해당 장소가 포함된 학년별 로드맵으로 바로 이동합니다.

### 활용 방법
1. 상단 **학년별 로드맵** 탭을 선택합니다.
2. 원하는 **학년 버튼**(1~6학년)을 눌러 해당 학년의 맞춤 자원 목록을 확인합니다.
3. 목록에서 자원을 선택하면 오른쪽 상세 패널에서 설명, 태그, 권장 학년, 외부 링크 등을 확인할 수 있습니다.
4. 체험학습 탭의 장소 상세에서 **관련 로드맵 보기**를 통해 해당 장소와 연계된 학년별 코스를 탐색할 수 있습니다.

### 데이터 관리
- 구글 스프레드시트의 활용 시트에서 학년별 연계 정보를 관리합니다.
- 시트를 수정한 뒤 데이터 새로고침을 하면 로드맵에 즉시 반영됩니다.

## 📍 내 위치 기반 기능 (체험학습 탭)

### 기능 개요
체험학습(visitmap) 탭에서 사용자의 현재 위치를 활용하여, 가까운 체험학습 장소를 추천하고 지도 위에 내 위치를 표시하는 기능입니다.

### 기능 1: 내 위치 표시
- 지도 위에 **내 위치 마커**를 별도 아이콘(파란 원 또는 사람 아이콘)으로 표시
- 기존 장소 마커(빨간 핀)와 시각적으로 구분
- Kakao Maps의 `CustomOverlay`를 사용하여 파란색 펄스 애니메이션 원으로 표현 가능

### 기능 2: 가까운 장소 필터링
- **"내 근처" 버튼**을 지역 필터(중구, 동구, …) 옆에 추가
- 버튼을 누르면 브라우저 Geolocation API로 현재 위치를 가져옴
- 각 장소까지의 직선 거리를 계산하여 가까운 순으로 정렬
- 거리 정보(예: "1.2km")를 리스트 항목에 함께 표시

### 기술 구현 방향

**위치 가져오기**
- `navigator.geolocation.getCurrentPosition()` 사용
- HTTPS 환경 필수 (배포 환경에서는 기본 충족)
- 위치 권한 거부 시 안내 메시지 표시, 기존 기능에 영향 없음

**거리 계산**
- Haversine 공식으로 두 좌표 간 직선 거리 계산
- 모든 OFFLINE 자원의 `location.lat`, `location.lng`와 비교
- 별도 API 호출 불필요 (클라이언트에서 계산)

**내 위치 마커**
- `MapComponent`에 `userLocation` prop 추가
- Kakao Maps `CustomOverlay`로 파란색 원 + CSS 펄스 애니메이션 렌더링
- 내 위치 버튼 클릭 시 지도 중심도 내 위치로 이동

**UI 변경 사항**
- `EduMapsClient.tsx`: 체험학습 탭 필터 영역에 "내 근처" 버튼 추가 (Crosshair 또는 LocateFixed 아이콘)
- `MapComponent.tsx`: userLocation prop 수신 시 CustomOverlay로 파란 원 마커 렌더링
- 리스트 항목에 거리 배지 표시 (예: `0.8km`)

### 구현 난이도
- 내 위치 마커 표시: **낮음** (Kakao Maps CustomOverlay + Geolocation API)
- 가까운 장소 필터링/정렬: **낮음** (Haversine 거리 계산 + 배열 정렬)
- 두 기능 모두 외부 API 의존 없이 클라이언트 단독으로 구현 가능

## 📋 최근 개선사항 (2026.05.19)

### 탐색 및 연계 기능 강화
- **지도 자동 이동**: "내 근처" 필터 적용 시 내 위치 + 가장 가까운 5개 장소가 화면에 맞게 줌/중심점 자동 조정. 지역 필터(중구, 동구 등) 선택 시에도 해당 지역 마커들로 자동 이동. "전체" 클릭 시 초기 배율·중심점으로 복귀.
- **로드맵 연계 버튼 개선**: 체험학습·온라인 탭 상세 카드에서 학년별 로드맵 버튼이 개별 학년 단위로 분리되어 원하는 학년 로드맵으로 바로 이동 가능.
- **학년 간 전환**: 로드맵 탭 상세 카드에서 복수 학년이 연결된 자원은 학년 전환 버튼으로 즉시 전환 가능.
- **로드맵 전체 필터 시 자동 학년 선택**: 학년 미선택 상태에서 사이드바 아이템 클릭 시 해당 자원의 첫 번째 학년이 자동 선택되어 상세 정보가 바로 표시.
- **온라인 → 로드맵 연계**: 온라인 탭 상세 카드에서도 관련 로드맵이 있는 경우 학년별 이동 버튼 표시.

## 📋 이전 개선사항 (2026.05.04 ~ 2026.05.12)

### UI/UX 개선 (05.04 ~ 05.08)
- **온라인 탭 패들렛 레이아웃**: 데스크탑 환경에서 카테고리별 세로 열 형식으로 개선하여 더 직관적인 탐색 가능
- **네비게이션 간섭 감소**: 패들렛 컬럼의 위치를 조정하여 상단 네비게이션과의 겹침 최소화
- **태그 표시 개선**: 카테고리 배지 제거, 모든 태그 표시로 자원의 특성을 더 명확하게 인식 가능
- **학년 표시 통합**: 모든 학년(1~6학년)이 해당되는 자원은 "모든 학년"으로 통합 표시

### 랜딩페이지 기능 개선 (05.04 ~ 05.08)
- **기본 자료 표시**: 학년을 선택하지 않았을 때도 모든 학년의 월별 추천 자료를 표시하여 초기 사용 경험 개선
- **맞춤형 필터링**: 학년 선택 시에만 해당 학년의 자료로 필터링

### 필터 및 탐색 개선 (05.11 ~ 05.12)
- **"전체" 필터 칩 추가**: 체험학습·온라인·학년별 로드맵·월별추천 모든 탭에 명시적 "전체" 칩 추가. 학년별 로드맵은 학년 미선택 시 전체 항목 즉시 표시
- **웹사이트 버튼 전체 너비**: 온라인 자원 디테일 패널에서 웹사이트 버튼이 자원 타입 기준으로 전체 너비 적용 (탭 무관)
- **헤더 검색창 추가**: 체험학습·온라인·학년별 로드맵 탭 상단 헤더에 검색 아이콘 추가. 데스크탑은 입력 즉시 드롭다운 자동완성, 모바일은 랜딩 전체 검색 결과 페이지로 이동
- **히어로 타이틀 변경**: "우리 아이 자기주도학습을 위한 대구 체험·온라인 학습 길잡이"로 교체 (초등 자기주도학습 정보모아 취지 반영)
