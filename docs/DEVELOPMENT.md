# EduMaps 개발 및 데이터 가이드

이 문서는 EduMaps 플랫폼의 데이터 구조와 백엔드(GAS) 연동 방식을 설명합니다.

## 1. 데이터 구조 (구글 스프레드시트)

### '아이템' 시트 (핵심 정보)
| 필드명 | 설명 | 비고 |
| :--- | :--- | :--- |
| id | 고유 식별자 | 숫자 또는 문자열 |
| type | 리소스 유형 | `OFFLINE` 또는 `ONLINE` |
| title | 장소/자원 명칭 | 지도와 리스트에 표시됨 |
| category | 지역 또는 영역 | 오프라인(중구 등), 온라인(수리 등) |
| tags | 상세 속성 | 쉼표(,)로 구분하여 여러 개 입력 가능 |
| image_url | 이미지 주소 | 외부 URL 또는 `/images/파일명` |
| description | 상세 설명 | 카드 하단 소개 배너에 표시 |
| lat / lng | 좌표 | 'EduMaps 도구' 메뉴로 자동 입력 가능 |

### '활용' 시트 (학년별 로드맵)
- `linked_id` 필드를 통해 '아이템' 시트의 `id`와 연동됩니다.
- 학년별(1~6) 학습 주제, 탐구 질문, 사후 활동을 정의합니다.

## 2. 백엔드 (Google Apps Script)
- 소스 코드 위치: `docs/backend/code.gs`
- **배포 방법**: 
  1. 구글 시트 -> 확장 프로그램 -> Apps Script
  2. 코드 붙여넣기 후 '새 배포' -> '웹 앱' 선택
  3. '액세스 권한이 있는 사용자'를 '모든 사용자(Anyone)'로 설정

## 3. 로컬 이미지 사용법
1. 이미지를 `public/images/` 폴더에 넣습니다.
2. 스프레드시트의 `image_url`에 `/images/your_file.jpg`와 같이 입력합니다.

## 4. 데이터 갱신 (ISR)
- 사이트 접속 시 서버가 GAS에서 데이터를 가져와 캐싱합니다.
- 데이터 갱신 주기(`revalidate`)는 `src/app/[tab]/page.tsx`에서 수정 가능합니다.
