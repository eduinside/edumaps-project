# EduMaps Backend Guide (Google Apps Script)

EduMaps의 데이터는 구글 스프레드시트에서 관리됩니다.

## 1. 스프레드시트 구성
- **아이템**: 모든 장소와 온라인 자원의 기본 정보 (ID, 제목, 카테고리, 좌표 등)
- **활용**: 학년별 로드맵 상세 데이터 (교과, 월, 주제, 탐구 질문 등)
  - `linked_id` 필드를 통해 '아이템' 시트와 N:N 관계로 연결됩니다.

## 2. 정렬 매커니즘
- 사이드바의 목록은 **'활용' 시트에 입력된 행 순서**를 그대로 따릅니다.
- `code.gs`에서 각 데이터에 `usage_index`를 부여하여 프론트엔드로 전달합니다.

## 3. 스크립트 관리
- 소스 코드: `docs/backend/code.gs`
- **업데이트 방법**: 구글 시트의 Apps Script 에디터에 해당 코드를 붙여넣은 후, 반드시 **[새 배포]**를 통해 URL을 갱신해야 합니다.

## 4. 시트 도구 메뉴 (📍 EduMaps 도구)
스프레드시트 상단의 **📍 EduMaps 도구** 메뉴에서 사용합니다.

- **선택한 행 좌표 자동 입력**: 선택한 행의 `title`로 위경도(`lat`, `lng`)를 자동 입력합니다.
- **선택 영역 맞춤법 교정**: 선택한 텍스트 셀들의 오탈자·띄어쓰기·맞춤법을 교정해 **즉시 덮어씁니다**.
  - 실행 전 대상 셀 개수를 확인하는 창이 한 번 뜹니다(되돌리기 어려운 작업이므로).
  - 빈 셀·숫자·날짜·**수식 셀**은 자동으로 제외됩니다.
  - 외부 무료 맞춤법 검사기(다음 `grammar_checker`)를 이용하므로 **별도 API 키가 필요 없습니다**.
    (부산대 검사기는 서버 이전으로 비공식 호출이 불안정해져 같은 계열의 다음 검사기를 사용합니다.)
  - 비공식 외부 서비스에 의존하므로 서비스 응답 형식이 바뀌면 동작이 멈출 수 있습니다.
    이 경우 해당 셀은 **'실패'로 처리되어 원문이 그대로 보존**되며(잘못된 값으로 덮어쓰지 않음),
    교정 완료 알림에 실패 개수가 표시됩니다.
  - 셀이 매우 많으면 실행 시간 제한(약 6분)에 걸릴 수 있어 사전 경고가 표시됩니다.
